# 🥊 Projeto Boxe

## 📌 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de apresentar informações sobre o mundo do boxe, sua história, fundamentos, regras, golpes, treinamentos, lutas e principais campeões da modalidade.

O site foi desenvolvido utilizando apenas **HTML**, seguindo a proposta da atividade de trabalhar a estrutura e organização de páginas sem a utilização de CSS e JavaScript.

## 📚 Conteúdo do projeto

O projeto possui mais de 10 páginas HTML, abordando diferentes assuntos relacionados ao boxe:

- 🏠 Página inicial
- 📖 História do boxe
- 🥊 Fundamentos do boxe
- 📋 Regras
- 👊 Principais golpes
- 🏋️ Treinamento
- 🥊 Lutas
- 🏆 Campeões
- 📂 Categorias
- 🖼️ Galeria
- 🎬 Mídia
